# THREE Desktop

Desktop software for the [Matter and Form THREE](https://matterandform.net) 3D scanner,
for Windows and Linux.  Scan capture happens on the scanner; everything else --
meshing, texturing, aligning, merging, project management -- runs on your computer.

This repository hosts **downloads and bug reports** for the beta program.

New to GitHub?  Read the [Beta Tester Guide (PDF)](THREE-Desktop-Beta-Guide.pdf) --
it walks through downloading, installing, and reporting bugs step by step.

## Download

Grab the latest installer from the [Releases](../../releases) page:

| Platform | File |
|----------|------|
| Windows 10/11 (x64) | `THREE-Desktop-<version>-win-x64.exe` |
| Linux (AppImage, most distros) | `THREE-Desktop-<version>-linux-x86_64.AppImage` |
| Linux (Debian/Ubuntu package) | `THREE-Desktop-<version>-linux-amd64.deb` |

The Windows installer is code-signed by Matter and Form Inc.

## Reporting a bug

1. Update to the latest release first -- your bug may already be fixed.
2. Open a [new bug report](../../issues/new/choose) and fill in the form.
3. **Attach exported logs.**  In the app: Menu, then Export Logs.  Drag the
   resulting zip into the issue.  This is the single most useful thing you can
   include.

For anything that isn't a bug (questions, account or ordering help), email
[info@matterandform.net](mailto:info@matterandform.net).

## Joining the beta

Email [info@matterandform.net](mailto:info@matterandform.net) with the subject
line **THREE Desktop Beta Tester** and the system you plan to test on (OS, CPU,
RAM, GPU).

## About this repository

The application source is developed in a private repository; this public one
exists so beta testers can download builds and report issues without needing
any special access.
